FAQ

Questions, answered

Is VidGrab really free?

Yes — 100% free, forever. No ads, no in-app purchases, no "pro" tier and no tracking. It's an open-source project built on yt-dlp, and it will stay that way.

Which sites are supported?

Hundreds of them: YouTube, Facebook, Instagram, X (Twitter), Vimeo, Reddit, TikTok, SoundCloud, Dailymotion and more. Anything yt-dlp supports works in VidGrab — and the list grows with every update.

Where are my downloads saved?

Videos go to VidGrab/Video and audio to VidGrab/Audio in your internal storage. Both folders appear immediately in your gallery and any file manager — nothing is buried in hidden directories.

Is VidGrab safe?

Yes. VidGrab is open source, so every line of code can be audited. It contains no ads, no analytics and no trackers, and it only asks for the storage access it needs to save your files.

Why does Android warn me during install?

Because VidGrab isn't distributed through the Play Store. Android shows a standard warning for every sideloaded APK — it's normal and expected. As long as you downloaded the file from the official GitHub releases, confirm and continue.
